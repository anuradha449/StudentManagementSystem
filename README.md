# 📖 Overview

The **Student Management System** is a Java-based desktop application designed to efficiently manage student records. It provides an organized way to perform student-related operations such as adding, updating, deleting, and searching student information.

The project demonstrates the implementation of **Object-Oriented Programming (OOP)** concepts, Java Collections, and modular programming to build a simple and user-friendly management system.

# ⚙ Getting Started

## Prerequisites

- Java JDK 17 or above
- IntelliJ IDEA (Recommended)
- Git

---

## Installation

Clone the repository:

```bash
git clone https://github.com/anuradha449/StudentManagementSystem.git
```

Open the project in IntelliJ IDEA.

Compile and run the project:

```bash
javac *.java
java Main
```
